## AI reactions

In-game character reactions may be generated by an AI model when a network API is available. If the API is unavailable, the game uses the written fallback lines in `assets/content/encounters.json`.

- **AI provider:** Groq API (free tier), model openai/gpt-oss-20b.
- The AI produces only a short in-character line of text. It does not decide scoring, health, or progression.

## Assets

- **Pixel art (all sprites, tiles, candles, hearts):** drawn in code by the Campus Crypt engine (`src/art.rs`) as small text grids. There are no image files and no third-party art.
- **Sound effects:** synthesized in code at startup (`src/audio.rs`, from Delve). No third-party sounds.
- **Music** (`assets/audio/`, copied to `web/assets/audio/`): "Campus Crypt — Floor Themes & Title March" (v3 remaster), original compositions written and generated by Dey for Campus Crypt. They develop an original Fight March motif (a falling major 3rd, a leap of a 5th, then a stepwise descent) in a 32-bit-era console-RPG style (FM/additive brass, strings and pads, horn countermelody, harp and pizzicato, timpani, snare, cymbal swells, bass; stereo with hall reverb). Ten seamless floor loops escalate from 100 BPM (floor 1, D major) to 150 BPM (floor 10, E major), plus a 128 BPM title march. 32 kHz stereo Vorbis. v3 is a louder, clearer remaster of v2 with the same compositions and loop lengths: brighter voices, drier reverb, an 80 Hz high-pass on the pads, a gentle high shelf, loudness matching (about −16 to −15 LUFS on floors 1–5, about −14 LUFS on the title and floors 6–10) and a −1 dBTP true-peak limiter. Full music credits: [assets/audio/CREDITS.md](../assets/audio/CREDITS.md). License: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/), dedicated to the public domain. Not a quotation, paraphrase, arrangement, or derivation of the Kennesaw State University fight song (James Sochinski, 2012), nor of any other existing fight song, march, or game soundtrack. Tracks: `title_march.ogg` (title screen), `floor_01.ogg` ... `floor_10.ogg` (one per floor).
- **Fonts:** Source Code Pro Bold by Adobe (`assets/fonts/SourceCodePro-Bold.ttf`, SIL Open Font License 1.1, license in `assets/fonts/OFL.txt`) for body text, so it stays sharp at any size; ProggyClean by Tristan Grimmer, bundled inside macroquad as its default font (MIT license), for the pixel-style titles.
- **Rust crates in the build:**
  - [macroquad](https://github.com/not-fl3/macroquad) 0.4, with miniquad and quad-snd: windowing, drawing, audio. MIT OR Apache-2.0.
  - [serde](https://serde.rs) and [serde_json](https://github.com/serde-rs/json): reading `encounters.json`. MIT OR Apache-2.0.
  - [lewton](https://github.com/RustAudio/lewton) 0.9: decoding the Ogg Vorbis music on a background thread. Native only. MIT OR Apache-2.0.
  - [ureq](https://github.com/algesten/ureq) 2: HTTPS call for AI reaction lines. Native only, optional `ai` feature. MIT OR Apache-2.0.
  - [serialport](https://github.com/serialport/serialport-rs) 4: optional Arduino controller link. Native only, optional `hardware` feature. MPL-2.0.
- **Web runtime:** `web/gl.js` and `web/audio.js` are copied from miniquad and quad-snd. MIT OR Apache-2.0.

This game teaches warning signs and a safer next step. It does not claim to prevent scams or improve grades.
